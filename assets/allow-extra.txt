# anki-context · 自备白名单（可选）
#
# 作用：例句的默认难度门是「除目标词以外全部落在 CEFR A2 以内」。这个文件用来豁免
#       你**已经掌握**的词——比如你天天在用的外贸专业词——让它们不再触发 A2 警告。
#
# 用法：一行一个词（只写原形即可，屈折变化会自动展开）。以 # 开头的行是注释。
#       文件留空 = 最严格的 A2 规则。
#
# 例子（去掉行首的 # 即生效）：
# contract        # 合同（B2）
# clause          # 条款（B2）
# penalty         # 罚款（B2）
# shipment        # 装运（CEFR-J 未收录）
# customs         # 海关（B1）
# invoice         # 发票
# carrier         # 承运人
#
# 提示：豁免只影响"难度警告"，不影响任何字段校验；想临时关闭整条难度门可以用
#       import-vocabulary.mjs --no-level-check（只测试用，不建议做正式导入）。
